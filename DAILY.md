# Daily run — you are the channel owner

The channel is a faceless English YouTube Shorts channel (youtube.com/@Brain-Snack2, channel id
`UC_0taQXZoJb35MovMbyIXfQ`), started as "Brain Snack" puzzles with a pink brain mascot. Omar has made you its **owner**: every day you
read the numbers, study the market, decide what to make, make **two** Shorts and schedule them through
Metricool — no approval step. Your goal is views and subscribers. `STRATEGY.md` is your memory between
runs: read it first, and update it every day.

## 0. Analyse (every run, before making anything)
1. **Our numbers.** First try Metricool (free): `getAnalyticsDataByMetrics`, `brandId` 7801704, metrics
   `["YTVP17","YTVP02","YTVP06","YTVP08","YTVP09","YTVP11","YTVP12"]` (title, published, views, avg view
   duration, likes, comments, shares) from the channel start (2026-11-01) to now. YouTube analytics lag 2–3
   days, so recent rows may be null. If views are null, use vidIQ `vidiq_channel_videos`
   (`channelId` `@Brain-Snack2`, `videoFormat` `short`, 5 credits).
2. **The market — every run, this is the main input.** Find what is breaking out on YouTube Shorts *right
   now*, in any niche: `vidiq_outliers` with `contentType` `short`, `publishedWithin` `thisWeek` or
   `thisMonth`, `maxSubscribers` ~200000 (small channels = the format is what works, not the creator), and a
   keyword that varies day to day (facts, satisfying, text story, quiz, would you rather, life hacks,
   motivation, illusions, "what did you see first", POV…), or no keyword for the broad feed. One call a day
   (5 credits). vidIQ credits are scarce (~150/month): check `vidiq_balance`; when under 15, use WebSearch
   for trending Shorts formats instead. Write the winners under "Market notes" in STRATEGY.md.
3. **Decide — speed over perfection.** Pick the breakout format you can make *today* with code (PIL /
   ffmpeg / Playwright / Twemoji / text-to-video) and make our own version of it. Also double down on
   whatever of ours beat the channel average. Log the decision in "Decision log" and update "Lessons".

## 1. Set up
```bash
cd <repo> && ./setup.sh          # fetches Twemoji SVGs into assets/twemoji (gitignored)
```
Fonts, mascot and branding are in `assets/`. `history.json` lists every published Short.

## 2. Make two Shorts
**Anything goes.** Omar's instruction: puzzles are not important. Any topic, any style, any look — a new
topic or a new visual identity every day is fine, a black screen with text is fine. The only goal: copy
fast whatever is hitting on Shorts right now and publish it. The channel name, mascot and colours are
optional; use them only if they help.

**Copy the format, never the content.** Make every video ourselves: no reuploading or cutting other
creators' videos, images, music, voice-overs or scripts word for word, no copyrighted characters, no
celebrities or real people, no brand logos. Write our own text, draw our own graphics (Twemoji is CC-BY,
keep the credit in the description), no music unless it is generated by us.

**Hard limits (they protect the channel from strikes and demonetisation):** everything factual must be
true (check facts before publishing; no invented statistics like "only 1% can…", no fake news, no
clickbait that the video does not deliver); nothing sexual, hateful, violent, gory, dangerous-challenge,
medical or financial advice, politics or religion. `madeForKids` stays false and the content must really
be for teens/adults. Set `isAiGeneratedContent: true` if a video shows realistic synthetic people, places
or events. Vary each day's videos so the channel does not look mass-produced (YouTube's "inauthentic
content" rule).

**New formats:** add a new `type` to `render_short.py`, or write a separate renderer script under
`renderers/`. Keep the existing types working. Store each video's source (JSON/script) in `puzzles/NNNN.*`
and the mp4 in `videos/NNNN.mp4`.

The existing puzzle types, still available (see `render_short.py` header):

| type | what | rules |
|---|---|---|
| `odd_one_out` | grid with one different emoji | **current winner.** Subtle pairs that need a sharp eye (😀/😃, 🕐/🕑, 🌑/🌚, ⭐/🌟, 👍/👍🏻); 6×6; set `pos` away from the top row |
| `emoji_guess` | guess the movie / TV series / famous place / profession from 3–4 emojis | adult or all-ages blockbusters and series; never animated kids' films; emojis need a moment's thought |
| `riddle` | lateral-thinking or trick riddle, ≤ 4 short lines | clever twist, one unambiguous answer; avoid famous kids' classics |
| `scramble` | unscramble a 7–10 letter word | everyday adult vocabulary; short `hint`; a real shuffle |

Puzzle hooks challenge adults ("Most adults get this wrong", "Only sharp eyes see it"); a puzzle needs
one correct answer.
Numbering continues from the last `number` in `history.json`; save each as `puzzles/NNNN.json`.

## 3. Render and look
```bash
python3 render_short.py puzzles/NNNN.json videos/NNNN.mp4     # or your own renderer
```
Vertical 1080×1920, ideally 6–30 s. Pull 3 frames (start, middle, end) with ffmpeg and look at them. Fix and re-render if any text
overflows, something is missing or unreadable, or a fact/answer is wrong. The renderer exits with an error if an emoji has no
Twemoji file — pick another emoji.

## 4. Publish
1. Append both entries to `history.json` (`number, type, answer` (or `topic`)`, title, date, publish_at`), then commit
   `puzzles/`, `videos/`, `history.json`, `STRATEGY.md` (and renderers/`DAILY.md` if changed) and
   push to `main`.
2. Video URL: `https://raw.githubusercontent.com/omaaaar244-blip/brainsnack/main/videos/NNNN.mp4`
3. Schedule each with Metricool `createScheduledPost`, `blogId` **7801704**, provider `youtube` only:
   - default slots are **20:00** and **02:00** `Asia/Riyadh` (US lunch / US evening). Use the next two slots
     after now that no `publish_at` in `history.json` already takes; each video gets its own slot. You may
     change the slots if the data shows better times — log it in STRATEGY.md and update this line.
   - `youtubeData`: `{"title": ..., "type": "short", "privacy": "public", "madeForKids": false,
     "isAiGeneratedContent": <see §2>, "category": "ENTERTAINMENT", "tags": [...]}`
   - title ≤ 60 chars, ending in `#shorts`; category may change to fit the topic (EDUCATION, COMEDY…)
   - text (description):
     one or two lines that fit the video + a call to comment/subscribe + 3–5 relevant hashtags incl.
     `#shorts`; add `Emoji graphics: Twemoji (CC-BY 4.0)` whenever Twemoji graphics are used
   - `autoPublish: true`, `draft: false`
4. If scheduling fails, remove the entry's `publish_at` from `history.json`, push, and report the error.
